

# 🚀 LiveStream Code Editor

**Trình soạn thảo mã nguồn trực tiếp (HTML/CSS/JS) với hỗ trợ Real-time Console và CDN.**

LiveStream Code Editor là một ứng dụng web cho phép lập trình viên, người học code hoặc nhà thiết kế viết, chỉnh sửa và xem trước trực tiếp mã nguồn HTML, CSS và JavaScript theo thời gian thực. Công cụ được tối ưu hóa cho mọi thiết bị từ Desktop, Tablet đến Mobile.

---

## ✨ Tính năng nổi bật

- 📝 **Soạn thảo đa file**: Hỗ trợ 3 tab chính cho `index.html`, `style.css`, và `script.js`.
- 👁️ **Xem trước thời gian thực (Live Preview)**: Tự động cập nhật khung xem trước khi gõ (Auto-run) hoặc bấm nút Run thủ công.
- 📟 **Console Output tích hợp**: Bắt log, hiển thị thông báo và lỗi JavaScript trực tiếp trong giao diện, giúp debug nhanh chóng.
- 📚 **Tích hợp CDN nhanh**: Hỗ trợ nạp nhanh các thư viện phổ biến chỉ với 1 click (Tailwind, Bootstrap, FontAwesome, Three.js...).
- 📤 **Chia sẻ & Xuất mã**: Dễ dàng xuất code hoặc chia sẻ dự án.
- 🔄 **Khôi phục mặc định**: Tính năng Reset toàn bộ mã nguồn về trạng thái ban đầu với hộp thoại xác nhận an toàn.
- 📱 **Responsive Design**: Giao diện linh hoạt, tương thích hoàn hảo trên Desktop, Tablet và Mobile.
- ⚡ **Trạng thái hoạt động**: Hiển thị trạng thái "Hoạt động thời gian thực" giúp người dùng yên tâm khi sử dụng.

---

## 📦 Thư viện CDN được hỗ trợ

Công cụ cung cấp sẵn menu tích hợp các CDN phổ biến, tự động nạp vào khung xem trước:

| Thư viện | Mô tả |
| :--- | :--- |
| **Tailwind CSS (v3)** | Framework Utility-first CSS phổ biến. |
| **Bootstrap 5** | Giao diện responsive và các component có sẵn (CSS + JS). |
| **FontAwesome 6** | Bộ biểu tượng icons phong phú. |
| **Animate.css** | Bộ hiệu ứng chuyển động CSS sẵn có. |
| **Three.js** | Thư viện đồ họa 3D WebGL mạnh mẽ. |
| **jQuery (3.7)** | Thao tác DOM và xử lý sự kiện JS nhanh chóng. |

## 🛠️ Hướng dẫn sử dụng

1. **Mở ứng dụng**: Mở file `liveCode2.html` trên bất kỳ trình duyệt web hiện đại nào (Chrome, Edge, Firefox, Safari...).
2. **Viết mã**: Chuyển đổi giữa các tab `index.html`, `style.css`, `script.js` ở thanh điều hướng để viết mã.
3. **Xem kết quả**: Khung xem trước (Preview) sẽ tự động cập nhật (nếu bật Auto-run) hoặc bạn nhấn nút **Run**.
4. **Debug**: Theo dõi các `console.log()` hoặc lỗi ở khung **Console Output** phía dưới.
5. **Nạp thư viện**: Nhấn vào biểu tượng **Thư viện** ở thanh công cụ, tích chọn các CDN cần thiết và nhấn **Áp dụng**.
6. **Reset**: Nếu muốn làm lại từ đầu, nhấn **Khôi phục** và xác nhận ở hộp thoại.

## 🖥️ Yêu cầu hệ thống

- **Trình duyệt**: Bất kỳ trình duyệt web hiện đại nào hỗ trợ HTML5, CSS3 và ES6 JavaScript.
- **Thiết bị**: Hoạt động mượt mà trên PC, Laptop, Máy tính bảng và Điện thoại thông minh.
- **Internet**: Cần kết nối mạng để tải các thư viện CDN (nếu có sử dụng).
